This is a DATA colour: it carries scientific meaning and must never be re-tinted
by system theming, a tint colour, or Increase Contrast.

Bare skeleton. The 0.7 stop of the severity ramp.

The light value is NOT the dark one lightened. On a light surface bone-white is
invisible, so the bleached end becomes parched sand; the direction of the scale -
saturated life to drained skeleton - is what is preserved, not the hue.
